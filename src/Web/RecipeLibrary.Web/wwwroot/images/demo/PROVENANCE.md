## Prompt set

The same base prompt was used once per dish:

> Create one photorealistic natural food photograph for a recipe application demo: [dish]. A single prepared dish, natural window light, ceramic bowl or plate on a simple light wooden kitchen table, appetizing realistic home cooking, centered composition that also works cropped as a recipe card, no text, no watermark, no logos, no people. This is one standalone asset.
